Жуп же так сан

        
Сан 2ге калдыксыз бөлүнсө жуп, болбосо так.


let san = Number(prompt("Сан киргиз:"));

if (san % 2 === 0) {
  console.log("Бул жуп сан");
} else {
  console.log("Бул так сан");
}

        

          
          
        

        

      


      

        
Кошуучу программа

        
Эки сандын суммасын, айырмасын жана көбөйтүндүсүн табат.


let a = Number(prompt("Биринчи сан:"));
let b = Number(prompt("Экинчи сан:"));

console.log("Сумма:", a + b);
console.log("Айырма:", a - b);
console.log("Көбөйтүү:", a * b);
